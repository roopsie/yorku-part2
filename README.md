# YorkU Lab Booking System

This project is a JavaFX-based application designed to manage lab reservations at York University.
It allows different types of users (such as coordinators, lab managers, and students) to interact with the system, approve bookings, and manage equipment availability.

## Features
- JavaFX graphical user interface
- User role–based screens (Coordinator, Lab Manager, etc.)
- Equipment management
- Reservation creation and approval workflow
- Input validation and error handling
- Maven-based project structure

## Technologies Used
- **Java 21**
- **JavaFX**
- **Maven**
- **Object‑oriented design principles**

## How to Build and Run

Make sure you have Java 21 installed.

From the project root:

```bash
cd ~/yorku-part2/yorku-lab-booking
mvn clean compile
mvn javafx:run
